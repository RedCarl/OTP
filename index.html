OTP令牌

iPhone 上的两步验证码管理器。验证码在本机生成，令牌存在你的 iCloud 钥匙串，换手机自动回来。

本地生成、iCloud 同步、不设账号。没有服务器，没有统计，没有广告。

能做什么

  • TOTP / HOTP，SHA-1 / 256 / 512，6–8 位，符合 RFC 4226 / RFC 6238
  • 扫码、粘贴链接、相册识别、手动输入、导入文件五种添加方式
  • 点一下复制验证码，剪贴板定时清空；40+ 品牌图标自动识别
  • iCloud 钥匙串端到端加密同步；iCloud 云盘备份，最多 10 份
  • 面容 ID / 设备密码解锁，切后台遮挡；中英…（界面为简体中文）
  • 迁移：Google Authenticator、Aegis、2FAS、otpauth 链接
