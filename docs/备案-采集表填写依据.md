补充证据：

- **不联网**：60 个 Swift 文件里没有 `URLSession` / `NSURLConnection` / `import Network` / `WKWebView`；唯一的 `UIApplication.shared.open` 是跳系统设置页（`openSettingsURLString`）。
- **不采集**：`PrivacyInfo.xcprivacy` 的 `NSPrivacyCollectedDataTypes` 为空数组，`NSPrivacyTracking = false`，仅为 UserDefaults 声明 CA92.1。
- **语言**：`OTP/Resources/Localizable.xcstrings`（zh-Hans 源语言 + en）与 `en.lproj` / `zh-Hans.lproj` 的 `InfoPlist.strings`；设置页可选「跟随系统 / 简体中文 / English」。
- **数据在哪**：令牌 = iCloud 钥匙串条目（`service cn.carljoy.otp.token`，端到端加密）；备份在用户自己的 iCloud Drive `OTP/Backups`。两者都不经过开发者服务器。
- **敏感权限**：相机（扫码）、Face ID（解锁），用途说明已写在 Info.plist。

## 二、定稿口径（2026-11-17 确认）

| 项 | 结论 |
|---|---|
| 域名 | `otp.carljoy.cn`，不要求解析成功 |
| 软件名称 | `otp令牌`，App Store Connect 里用同一串 |
| 服务内容 | 12-信息传输、软件和信息技术服务业 / 4-软件开发 |

服务内容为什么选这个：本应用是「本地生成验证码的软件产品」，没有互联网信息服务，按软件产品归到 12/4 是常规做法，也和主体此前那个 App 的填法一致，接入商/管局不会追问。若接入商坚持按安全类归，才需要改成「14-安全 / 5-加密软件」（两级必须对应）。

显示名说明：`OTP/Resources/Info.plist` 的 `CFBundleDisplayName` 仍是 `OTP`，那是图标下面的短名，和备案名/商店名不冲突；要连它一起改成 `otp令牌`，改这一行即可。

## 四、公钥与签名 MD5

接入商要求这两格必填。iOS 没有 APK，最贴近的就是「这个 App 用哪支证书签名上架」——取 App Store 分发描述文件里的那支：

| 项 | 值 |
|---|---|
| 证书 | `Apple Distribution: lei sun (BCRZR3P4AP)` |
| 来源 | `iOS Team Store Provisioning Profile: cn.carljoy.otp`（`~/Library/Developer/Xcode/UserData/Provisioning Profiles/c229f97a-….mobileprovision`） |
| 序列号 | `0F27054496A80C5AA4C0D61EDC0989ED` |
| 有效期 | 2026-11-16 → 2027-11-16 |
| 公钥 | RSA 2048，Base64（X.509 SubjectPublicKeyInfo），已填第 47 行 |
| 签名 MD5 | `D8:6A:3A:27:33:74:31:B6:33:C7:25:80:F6:68:17:86` |
| 证书文件 | 已导出到项目根 `OTP-AppleDistribution.cer` |

复核命令：

```bash
security cms -D -i "~/Library/Developer/Xcode/UserData/Provisioning Profiles/c229f97a-a516-49f5-aa1b-38a32af0a0ad.mobileprovision" > /tmp/p.plist
# 从 DeveloperCertificates 取出 DER 证书存为 /tmp/otp.cer 后：
openssl x509 -inform DER -in /tmp/otp.cer -noout -fingerprint -md5          # 签名 MD5
openssl x509 -inform DER -in /tmp/otp.cer -noout -pubkey \
  | openssl pkey -pubin -outform DER | base64 | tr -d '\n'                  # 公钥
```

**注意**：证书 2027-11-16 到期，续期后会换新证书，这两位要跟着更新，否则与实际签名对不上。
